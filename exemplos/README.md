# Documentos de exemplo

PDFs para desenvolver e testar. Os dados pessoais foram substituídos.

```
exemplos/
├── holerite-1.pdf
├── holerite-2.pdf
├── holerite-3.pdf
├── holerite-4.pdf
└── holerite-01.xlsx
```

Os PDFs de holerite ficam diretamente nesta pasta e fazem parte da entrega. Os arquivos de cartão de ponto são mantidos apenas como referência do enunciado; esse fluxo não compõe o escopo implementado.

## Importante

Nem todos os PDFs têm camada de texto. Parte deles é imagem escaneada; a solução deve reconhecer esse caso e usar OCR.
